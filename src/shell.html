地图与模型

密钥只保存在本机浏览器（localStorage），不会上传。

高德地图

不填也能用：底图瓦片、行政边界、内置点位全部可用。填入 JS API Key 与安全密钥后，可启用高德 POI 检索、路径规划与实时路况。

大模型

兼容 OpenAI 协议的任意服务（DeepSeek、通义千问、Kimi、Ollama、自建网关）。留空时使用内置证据引擎，仍然逐句带来源。本机或另一台电脑上的 Ollama 千问 4B 也能接：接口地址填 http://127.0.0.1:11434/v1（换机器就填 http://那台电脑的IP:11434/v1），模型填 ollama list 里的名字，Key 可留空。

联网检索

浏览器直连会被跨域拦截，推荐配合随包的 server.mjs（node server.mjs）使用：它代理搜索引擎、政府官网与公众号文章的抓取。也可以直接填搜索 API Key。

外观

坐标：内置点位为 WGS-84，渲染到高德底图时自动转换为 GCJ-02；切换底图不会造成偏移。
